# Coquí Solitaire Documentation

## Overview
Coquí Solitaire is a pixel-art solitaire game inspired by Puerto Rican culture and the iconic coquí frog. Built for the web and deployed on Remix.gg (Base), it features:

- Classic solitaire gameplay
- Custom pixel art and sound
- Mobile-first, portrait orientation
- Onchain-ready and Farcade/Remix SDK integration

## Game Rules
- Build down in alternating colors
- Move all cards to the foundations to win
- Tap the deck to flip new cards
