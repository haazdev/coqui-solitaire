# Coquí Solitaire 🐸

A pixel-art Puerto Rican solitaire game built for the web and deployed on [Remix.gg](https://remix.gg) (Base chain).

---

## Features
- 🃏 Classic Klondike solitaire gameplay with traditional scoring
- 🐸 Coquí frog theme and custom pixel art
- 🇵🇷 Puerto Rican cultural vibes with El Yunque landscape
- 🚀 Built for Remix.gg (Base chain) with Farcade SDK integration  
- 🎨 8-bit pixel art aesthetic
- 📱 Mobile-optimized touch controls
- 🎵 Authentic coquí frog sound effects

## How to Play
- **Drag cards** to move them between piles
- **Double-tap** for auto-move to foundations
- **Build down** by alternating colors in tableau
- **Build up** by suit in foundations (Ace to King)
- **Click stock pile** to reveal new cards (1 at a time)
- **Score points** for moves: Foundation (+10), Waste to Tableau (+5), Turn card (+5)
